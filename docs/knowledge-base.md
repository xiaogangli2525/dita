# 离线知识库发布

入口为顶部 **知识库 ↗**，或 **文件 → 发布知识库**。交付文件为 ZIP，解压后双击 `docs/index.html`，无需安装 Node 或启动服务器。

## 多仓库统一发布

1. 各功能库先加载到本机：已有本地库放在配置的仓库目录；远程库先通过工作台“加载远程库”克隆。批量发布读取本地来源，不自动 fetch/pull。
2. 打开“知识库”，填写统一的型号、SDK 版本和知识库名称。
3. 点击“添加文档库手册”，选择 HTTP、TCP、MQTT 等不同仓库。每份手册独立选择入口、读取方式、正文 DITAVAL、注脚前缀策略、文档版本和模块，然后“加入发布方案”。重复此步配置所有功能库，无需切换正在编辑的仓库。
4. 点击“核对全部来源”。系统依次读取并渲染各手册，逐项显示进度和错误，最后再次检查来源是否变化。
5. 失败项会拦住导出。点卡片“编辑来源”处理配置，或在原库处理保存/规则问题后点“重试未完成项”；通过项保留。也可只点某张卡片“重新核对”。取消会丢弃本轮未封存的结果，迟到响应不能恢复可下载状态。
6. 全部就绪后预览、导出一个离线 ZIP。统一阅读入口和跨手册搜索，功能手册仍各自独立；源库结构与原始 DITA 不改动。

“当前库快速加入”继续支持正在编辑库的一份或多份手册。第一份来源加入方案后固定型号，更换型号先清空集合。同一仓库的同一入口在方案中保留一个版本，重新配置会替换该入口。已指定 Git 版本的入口不能被“当前库快速加入”覆盖；需要改变读取方式时，通过卡片“编辑来源”明确修改。

### 两种读取方式

- **已保存文件**：读取该仓库当前分支的磁盘内容，可以包含已保存但尚未提交的修改。方案记录的分支必须仍与实际分支一致；不一致时明确报错。当前编辑器中与这份手册有关的未保存内容会阻止核对；无关草稿保持原样。
- **指定 Git 版本**：填写本地分支、标签或提交 SHA，也可选完整的 `refs/heads/...` / `refs/tags/...`。直接读取对应提交对象，不 checkout、不 stash、不覆盖工作目录。此方式不包含未提交修改；来源清单记录实际提交 SHA。命名引用核对期间发生变化会要求重试。LFS 指针、子模块、符号链接不会作为普通手册文件自动展开。

每份来源沿用自己的型号清单、独立注脚规则、DITAVAL、编码和图片。后台只接受配置目录内的独立 Git 库及当前库，不接受任意目录。XML/依赖、项目配置、注脚规则和图片都参与来源核对；缺失或变化会报错。每份来源最多 256 个文件、48 MiB 原始数据，单文件不超过 20 MiB；全文发布依赖另沿用 128 文件/8 MiB 文本限制。

### 保存和迁移方案

**发布方案可保存，正文快照不跨刷新保存。** “保存方案”保存统一型号/SDK 和每份手册的仓库、分支或 Git 版本、入口、条件、版本和检索属性。下次打开恢复最近方案，点击“核对全部来源”即可统一重建，不需要逐库切换。已封存内容不会随之后的编辑自动更新；发布前按需重新核对。

- 最多保存 20 份方案，以知识库名称和 SDK 版本区分；选择后点击“加载方案”。“另存新方案”保留当前集合，随后保存为独立配置。加载/导入会替换当前集合，先保存需保留的配置。
- “迁移配置”支持导入、导出方案 JSON，不包含正文、图片或密钥。导入后不会立即读取目录；通过“编辑来源”将每份手册关联到本机已加载的仓库，再批量核对。
- 卡片“核对来源/重新核对”直接读取指定仓库；“编辑来源”修改该份配置，不切换编辑器工作区。原条件文件不存在时须明确选择替代条件，不能静默退回不过滤。
- 同一方案在其它窗口更新时拒绝覆盖，可重新加载或另存。本地存储不可用时会显示错误，仍可导出 JSON。当前不自动拉取远程仓库，不提供增量构建。

## 检索属性

集合卡片“检索属性”可逐章设置使用指南/接口参考/示例/说明，补充搜索别名，以及确认该章正式定义的 AT 命令或 API。只修改发布配置，不改 DITA。符号从已过滤正文提取；正式定义优先于示例调用，未确认定义时仍可查看出现位置。

这些配置绑定章节路径与发布文本指纹。重新加入后原文变化、章节被移除或定义符号不再存在，会标为过期并阻止发布。核对后应用新属性，或清除旧配置再继续；保存方案可保留调整。

## 型号与正文边界

- 复用现有手册发布的项目型号、注脚独立规则、明确前缀和 DITAVAL 策略；原始 DITA 不变。
- 型号选择主要筛选注脚，正文由 DITAVAL 控制。知识库额外拦截发布后仍有明确其它型号 `product` 标记的正文，要求核对条件文件。
- 没有标记范围的正文无法自动判断是否通用；含 Oxygen 修订或未确认范围的注脚会在集合卡片提示，需要发布者核对。
- 页面、章节条目与全文索引均从同一份发布 HTML 生成；被过滤的正文和注脚不会进入搜索数据。

## 客户侧使用

- 首页按功能显示手册，左侧展开章节目录；顶部全文搜索支持 Ctrl/Cmd+K。
- 支持完整 AT 命令、参数名、数字错误码和中文关键词。正式定义优先于示例提及；命令、下划线参数和数字保持完整匹配，支持接口前缀搜索、中文分词与常见同义词。
- 可以限定手册、AT/OpenCPU 开发方式和功能模块。输入时显示当前范围的补全建议，方向键选择、Enter 搜索、Esc 收起。结果显示来源、匹配原因和命中摘要，点击定位章节并高亮关键词；“返回搜索结果”继续核对其它结果。
- “命令 / API 索引”列出当前范围的符号，可按前缀筛选并定位正式定义或出现位置。
- 代码可复制，图片已内嵌；相对锚点与注脚返回链接在离线环境工作。不同手册的同名 ID 不会相互覆盖。

首版以 Topic 章节为检索条目，保留完整上下文和所引用的注脚，不按固定字数切片。关键词检索不会生成技术答案；未命中时建议改用完整命令或更短关键词。

## 输出与验收

| 内容 | 路径 |
| --- | --- |
| 单文件离线门户，包含正文、索引、脚本和样式 | `docs/index.html` |
| 独立功能手册 HTML | `docs/manuals/<手册标识>.html` |
| 型号、SDK、各手册版本、Git 状态、来源路径/哈希、过滤策略、指定 Git 版本、图片哈希、开发方式/模块和章节检索属性 | `docs/manifest.json` |
| 使用说明 | `docs/README.txt` |

每包固定一个型号和一个 SDK 版本，不自动切换到新内容。本版上限为 30 份手册、40 MB 源内容；ZIP 使用无压缩方式打包。PDF/Word 可使用现有手册交付功能单独生成，不自动加入知识库包。

自动化使用真实 HTTP 库验证 25 个 Topic、25 条 ML307G 注脚；另用独立临时库验证同一方案无切换批量捕获、指定分支/标签/提交、失败重试、取消、草稿保留和跨仓库同名路径、正文条件与注脚排除、来源哈希、取消/未保存保护。解压包在中文和空格目录移动后，用 Chromium 的 `file://` 和断网模式验证搜索、阅读、复制和窄屏布局。实际 Windows Edge/Chrome 仍需现场核对。

预览样本由真实 HTTP 手册和其中的 HTTPS 示例组成。合成的隔离测试库不进入提供给用户的样本。
