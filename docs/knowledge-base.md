# 离线知识库发布

入口为顶部 **知识库 ↗**，或 **文件 → 发布知识库**。交付文件为 ZIP，解压后双击 `docs/index.html`，无需安装 Node 或启动服务器。

## 组合手册

1. 加载文档库，打开需要发布的功能手册。
2. 填写知识库名称、具体型号、SDK 版本，勾选一份或多份手册。
3. 选择本库的正文条件文件，按需启用明确型号前缀注脚筛选，填写本批手册的文档版本、开发方式（AT/OpenCPU/通用）与功能模块。
4. 点击“加入／更新手册”。加入内容为已保存快照；未保存、失效规则、图片/链接问题和其它型号的明确正文条件会阻止加入。
5. 可以关闭窗口，使用现有仓库选择器切换到其它功能库，再打开知识库继续添加。相同仓库和入口再次加入会替换原快照。
6. 预览目录、搜索与正文，再导出离线 ZIP。

第一份手册加入后固定型号；更换型号须清空集合。每批手册先全部检查，通过后才加入，失败或取消保留此前已加入的内容。

**发布方案可保存，正文快照不跨刷新保存。** “保存方案”将型号、SDK 版本、各仓库/分支/入口、文档版本、正文条件、注脚策略和检索属性保存在当前浏览器。下次打开恢复最近保存方案，集合显示“待重新核对”；必须逐份重新加入后才能导出。已加入快照不随之后的编辑自动变化，需要重新加入更新。

- 可保存多份命名方案（以知识库名称和 SDK 版本区分，最多 20 份），选择后点击“加载方案”。“另存新方案”保留当前集合，之后保存为独立配置。加载/导入会替换当前集合，先保存需保留的配置。
- “迁移配置”支持导出、导入方案 JSON。只保存配置、来源哈希和章节检索属性，不包含正文、图片、密钥。导入不自动读取任意目录；先用工作台选择文档库，必要时点卡片“关联当前库”明确重设本机来源，再核对路径和条件。
- 卡片“核对来源”恢复该份手册的发布条件；在其它仓库时提示切换位置。当前仓库的条件文件、前缀开关、文档版本与选择在窗口重开时保留，按仓库和分支隔离。丢失的条件文件会阻止加入，需明确选择替代条件。
- 本地存储不可用或写入失败会显示错误，仍可导出 JSON 保留配置。同一方案在其它窗口更新时拒绝覆盖，重新加载或另存即可。当前没有自动批量切换、拉取各仓库或增量生成。

## 检索属性

集合卡片“检索属性”可逐章设置使用指南/接口参考/示例/说明，补充搜索别名，以及确认该章正式定义的 AT 命令或 API。只修改发布配置，不改 DITA。符号从已过滤正文提取；正式定义优先于示例调用，未确认定义时仍可查看出现位置。

这些配置绑定章节路径与发布文本指纹。重新加入后原文变化、章节被移除或定义符号不再存在，会标为过期并阻止发布。核对后应用新属性，或清除旧配置再继续；保存方案可保留调整。

## 型号与正文边界

- 复用现有手册发布的项目型号、注脚独立规则、明确前缀和 DITAVAL 策略；原始 DITA 不变。
- 型号选择主要筛选注脚，正文由 DITAVAL 控制。知识库额外拦截发布后仍有明确其它型号 `product` 标记的正文，要求核对条件文件。
- 没有标记范围的正文无法自动判断是否通用；含 Oxygen 修订或未确认范围的注脚会在集合卡片提示，需要发布者核对。
- 页面、章节条目与全文索引均从同一份发布 HTML 生成；被过滤的正文和注脚不会进入搜索数据。

## 客户侧使用

- 首页按功能显示手册，左侧展开章节目录；顶部全文搜索支持 Ctrl/Cmd+K。
- 支持完整 AT 命令、参数名、数字错误码和中文关键词。正式定义优先于示例提及；命令、下划线参数和数字保持完整匹配，支持接口前缀搜索、中文分词与常见同义词。
- 可以限定手册、AT/OpenCPU 开发方式和功能模块。输入时显示当前范围的补全建议，方向键选择、Enter 搜索、Esc 收起。结果显示来源、匹配原因和命中摘要，点击定位章节并高亮关键词；“返回搜索结果”继续核对其它结果。
- “命令 / API 索引”列出当前范围的符号，可按前缀筛选并定位正式定义或出现位置。
- 代码可复制，图片已内嵌；相对锚点与注脚返回链接在离线环境工作。不同手册的同名 ID 不会相互覆盖。

首版以 Topic 章节为检索条目，保留完整上下文和所引用的注脚，不按固定字数切片。关键词检索不会生成技术答案；未命中时建议改用完整命令或更短关键词。

## 输出与验收

| 内容 | 路径 |
| --- | --- |
| 单文件离线门户，包含正文、索引、脚本和样式 | `docs/index.html` |
| 独立功能手册 HTML | `docs/manuals/<手册标识>.html` |
| 型号、SDK、各手册版本、Git 状态、来源路径/哈希、过滤策略、开发方式/模块和章节检索属性 | `docs/manifest.json` |
| 使用说明 | `docs/README.txt` |

每包固定一个型号和一个 SDK 版本，不自动切换到新内容。本版上限为 30 份手册、40 MB 源内容；ZIP 使用无压缩方式打包。PDF/Word 可使用现有手册交付功能单独生成，不自动加入知识库包。

自动化使用真实 HTTP 库验证 25 个 Topic、25 条 ML307G 注脚；另用独立临时库验证跨仓库同名路径、正文条件与注脚排除、来源哈希、取消/未保存保护。解压包在中文和空格目录移动后，用 Chromium 的 `file://` 和断网模式验证搜索、阅读、复制和窄屏布局。实际 Windows Edge/Chrome 仍需现场核对。

预览样本由真实 HTTP 手册和其中的 HTTPS 示例组成。合成的隔离测试库不进入提供给用户的样本。
