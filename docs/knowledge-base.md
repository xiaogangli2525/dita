# 离线知识库发布

入口为顶部 **知识库 ↗**，或 **文件 → 发布知识库**。交付文件为 ZIP，解压后双击 `docs/index.html`，无需安装 Node 或启动服务器。

## 多仓库统一发布

1. 各功能库先加载到本机：已有本地库放在配置的仓库目录；远程库先通过工作台“加载远程库”克隆。批量发布读取本地来源，不自动 fetch/pull。
2. 打开“知识库”，填写统一的型号、SDK 版本和知识库名称。
3. 点击“添加文档库手册”，选择 HTTP、TCP、MQTT 等不同仓库。切换后会自动显示该库的手册入口和正文条件文件。在磁盘上新增入口或读取失败后，可点“重新读取来源”。每份手册独立选择入口、读取方式、正文 DITAVAL、注脚前缀策略、文档版本和模块，然后“加入发布方案”。重复此步配置所有功能库，无需切换正在编辑的仓库。
4. 点击“核对全部来源”。系统依次读取并渲染各手册，逐项显示进度和错误，最后再次检查来源是否变化。
5. 失败项会拦住导出。点卡片“编辑来源”处理配置，或在原库处理保存/规则问题后点“重试未完成项”；通过项保留。也可只点某张卡片“重新核对”。取消会丢弃本轮未封存的结果，迟到响应不能恢复可下载状态。
6. 全部就绪后预览、导出一个离线 ZIP。统一阅读入口和跨手册搜索，功能手册仍各自独立；源库结构与原始 DITA 不改动。

“当前库快速加入”可一次添加采用相同发布设置的手册。已配置的手册若使用不同的过滤条件、版本或模块，请用“核对全部来源”沿用各自设置。第一份来源加入方案后固定型号，更换型号先清空集合。同一仓库的同一入口在方案中保留一个版本。重复添加会提示编辑已有卡片。已指定 Git 版本的入口不能被“当前库快速加入”覆盖；需要改变读取方式时，通过卡片“编辑来源”明确修改。

知识库发布暂时跳过公共库中的《服务与支持》（中文和英文对应主题）。该主题不出现在阅读页、章节目录和搜索条目中，缺少该文件也可继续发布。已有方案中该主题的检索属性会保留配置，但不阻止本次发布。普通手册导出仍保留这一章。公共库的技术章节、声明和图片继续按实际引用加载。

### 两种读取方式

- **已保存文件**：读取该仓库当前分支的磁盘内容，可以包含已保存但尚未提交的修改。方案记录的分支必须仍与实际分支一致；不一致时明确报错。当前编辑器中与这份手册有关的未保存内容会阻止核对；已使用的 Git 忽略文件也会标为未提交内容。
- **指定 Git 版本**：填写本地分支、标签或提交 SHA，也可选完整的 `refs/heads/...` / `refs/tags/...`。直接读取对应提交对象，不 checkout、不 stash、不覆盖工作目录。此方式不包含未提交修改；来源清单记录实际提交 SHA。命名引用核对期间发生变化会要求重试。已初始化的直接 Git 子模块可按父库锁定的提交读取；“已保存文件”模式读取其本机内容。缺少子模块或指定提交时会提示补齐本地来源。LFS 指针、符号链接和下一级子模块仍不自动展开。

每份来源沿用自己的型号清单、独立注脚规则、DITAVAL、编码和图片。后台只接受配置目录内的独立 Git 库及当前库，不接受任意目录。XML/依赖、项目配置、注脚规则和图片都参与来源核对；缺失或变化会报错。每份来源最多 256 个文件、48 MiB 原始数据，单文件不超过 20 MiB；全文发布依赖另沿用 128 文件/8 MiB 文本限制。

### 保存和迁移方案

**发布方案可保存，正文快照不跨刷新保存。** “保存方案”保存统一型号/SDK 和每份手册的仓库、分支或 Git 版本、入口、条件、版本和检索属性。下次打开恢复最近方案，点击“核对全部来源”即可统一重建，不需要逐库切换。已封存内容不会随之后的编辑自动更新；发布前按需重新核对。

- 最多保存 20 份方案，以知识库名称和 SDK 版本区分；选择后点击“加载方案”。“另存新方案”保留当前集合，随后保存为独立配置。加载/导入会替换当前集合，先保存需保留的配置。
- “迁移配置”支持导入、导出方案 JSON，不包含正文、图片或密钥。导入后不会立即读取目录；通过“编辑来源”将每份手册关联到本机已加载的仓库，再批量核对。
- 卡片“核对来源/重新核对”直接读取指定仓库；“编辑来源”修改该份配置，不切换编辑器工作区。迁移到新的本机目录时保留原入口和条件文件。路径缺失时会提示选择替代项。
- 同一方案在其它窗口更新时拒绝覆盖，可重新加载或另存。本地存储不可用时会显示错误，仍可导出 JSON。当前不自动拉取远程仓库，不提供增量构建。

## 检索属性

集合卡片“检索属性”可逐章设置使用指南/接口参考/示例/说明，补充搜索别名，以及确认该章正式定义的 AT 命令或 API。只修改发布配置，不改 DITA。符号从已过滤正文提取；正式定义优先于示例调用，未确认定义时仍可查看出现位置。

这些配置绑定章节路径与发布文本指纹。重新加入后原文变化、章节被移除或定义符号不再存在，会标为过期并阻止发布。核对后应用新属性，或清除旧配置再继续；保存方案可保留调整。

## 型号与正文边界

- 复用现有手册发布的项目型号、注脚独立规则、明确前缀和 DITAVAL 策略；原始 DITA 不变。
- 型号选择主要筛选注脚，正文由 DITAVAL 控制。知识库额外拦截发布后仍有明确其它型号 `product` 标记的正文，要求核对条件文件。
- 没有标记范围的正文无法自动判断是否通用；含 Oxygen 修订或未确认范围的注脚会在集合卡片提示，需要发布者核对。
- 页面、章节条目与全文索引均从同一份发布 HTML 生成；被过滤的正文和注脚不会进入搜索数据。

## 客户侧使用

- 首页按功能显示手册，左侧展开章节目录；顶部全文搜索支持 Ctrl/Cmd+K。
- 支持完整 AT 命令、参数名、数字错误码和中文关键词。正式定义优先于示例提及；命令、下划线参数和数字保持完整匹配，支持接口前缀搜索、中文分词、通信领域查询扩展、错别字容错和字段加权相关性排序。
- 可以限定手册、AT/OpenCPU 开发方式和功能模块。输入时显示当前范围的补全建议，方向键选择、Enter 搜索、Esc 收起。结果显示来源、匹配原因和命中摘要，点击定位章节并高亮关键词；“返回搜索结果”继续核对其它结果。
- “命令 / API 索引”列出当前范围的符号，可按前缀筛选并定位正式定义或出现位置。
- 代码可复制，图片已内嵌；相对锚点与注脚返回链接在离线环境工作。不同手册的同名 ID 不会相互覆盖。

首版以 Topic 章节为检索条目，保留完整上下文和所引用的注脚，不按固定字数切片。检索引擎 1.2.0 在原有精确命令/数字匹配和倒排索引上，增加通信领域词典、查询同义表达归一、单词编辑距离容错，以及按标题/别名/符号/正文分字段的 BM25 风格排序；模糊命中会在结果原因和命中词中标明。检索仍是确定性本地算法，不在每次查询时调用 AI，也不需要 Embedding 模型或网络。精确 AT/API 符号命中仍优先于模糊结果。

本轮实际验收文件为用户提供的 `ML307G-SDK-Preview-Knowledge.zip`：包含 2 份手册、26 个章节（HTTP/HTTPS 用户手册 25 章，独立 HTTPS 示例 1 章）。回归测试使用这 26 个真实章节标题和对应的短文本摘录，覆盖 20 条 HTTP/HTTPS 口语化查询、同义表达、AT 命令错字和精确命令查询。当前基准集 20/20 通过（Node.js 20/22）。这不是 4 份手册或 64 章的测试；如需验收另一份 MR380R 四手册知识库，应提供该 ZIP 后再补充对应测试。当前基准是定向回归，不代表所有用户问题的召回率保证；后续应继续根据实际搜索日志扩充。关键词检索不会生成技术答案；未命中时建议改用完整命令或更短关键词。

## 命令行检索

在项目根目录安装 Node.js 20+ 后，可用 `npm link` 注册本机命令；也可以直接运行 `node bin/blink-cli.js`。之后可查询离线知识库：

```bash
npm link
blink-cli --kb ./ML307G-SDK-Preview-Knowledge.zip "HTTP请求头怎么设置"
blink-cli "AT+MHTTPREAD" --json
blink-cli --list
blink-cli --info
blink-cli --get "手册ID#章节锚点" --json
```

CLI 可直接读取知识库 ZIP、解压目录、`knowledge.json` 或旧版 `index.html`。知识库位置通过 `--kb <路径>` 指定，也可设置 `BLINK_KB` 环境变量；未指定时会查找当前目录下的 `docs/knowledge.json`、`docs/index.html` 等默认位置。搜索复用网页端同一检索引擎，不生成答案、不访问网络。AI Agent 可用 `--json` 获取结果，再通过 `--get` 读取命中章节原文和来源。

新导出的 ZIP 增加轻量的 `docs/knowledge.json`，只包含章节文本和来源，不重复打包渲染后的完整 HTML 正文或网页编译索引；CLI 首次搜索时按当前检索引擎构建内存索引。旧版 ZIP 没有该文件时，CLI 会从受支持的离线入口 HTML 中读取嵌入的结构化数据，无需为了 CLI 单独重新导出旧包。

## 输出与验收

| 内容 | 路径 |
| --- | --- |
| 单文件离线门户，包含正文、索引、脚本和样式 | `docs/index.html` |
| 独立功能手册 HTML | `docs/manuals/<手册标识>.html` |
| 型号、SDK、各手册版本、Git 状态、来源路径/哈希、过滤策略、指定 Git 版本、图片哈希、开发方式/模块和章节检索属性 | `docs/manifest.json` |
| CLI/AI 机器可读章节、来源和检索索引 | `docs/knowledge.json`（新版本导出） |\n| 使用说明 | `docs/README.txt` |

每包固定一个型号和一个 SDK 版本，不自动切换到新内容。本版上限为 30 份手册、40 MB 源内容；ZIP 使用无压缩方式打包。PDF/Word 可使用现有手册交付功能单独生成，不自动加入知识库包。

自动化使用真实 HTTP 库验证知识库保留 24 个 Topic、25 条 ML307G 注脚，普通手册保留 25 个 Topic；另用独立临时库验证同一方案无切换批量捕获、指定分支/标签/提交、失败重试、取消、草稿保留和跨仓库同名路径、正文条件与注脚排除、来源哈希、取消/未保存保护。解压包在中文和空格目录移动后，用 Chromium 的 `file://` 和断网模式验证搜索、阅读、复制和窄屏布局。实际 Windows Edge/Chrome 仍需现场核对。

预览样本由真实 HTTP 手册和其中的 HTTPS 示例组成。合成的隔离测试库不进入提供给用户的样本。
