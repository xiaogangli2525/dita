## 附件中的知识库实现描述

结构化注脚绑定、离线 q8/512 维编码、16 块构建批次、单册缓存、Worker 打包与 RRF 融合的主流程与代码一致。以下表述需要区分：

- STORE 写入器未调用 fflate 属于实现选择；fflate 用在读取/导入 ZIP，依赖仍有效。
- Blob 分片拼装不等于网络流式下载，也不能据此保证零内存复制。
- 源快照限制为 40 MiB；ZIP 限制另为 64 MiB。生成前有精确大小检查。
- 数字/错误码具有严格证据约束；AT/API 支持前缀及纠错，词法分流不代表所有查询都只做字符串完全相等匹配。
- 模型与分块配置、正文、注脚和定位字段进入缓存身份；版本标签和发布时间不参与编码缓存身份。此次规则升级会使旧本机缓存首次重建，旧已交付索引继续可读。

完整测试结果以本次修复 PR 的 CI 为准，包含 Linux 浏览器、Node 20/22 及 Windows 离线模型和便携包检查。本地缺少模型文件时仅跳过真实推理用例，不将其计为通过。
