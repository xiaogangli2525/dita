# DITA 团队版设计文档

团队版是个人版稳定版本的独立演进分支，面向部门 30–50 人的内网使用。当前文档只定义目标，不代表团队功能已经实现。

## 已确认的产品决策

- Git：公司内网 GitLab/Gitea。
- 登录：DITA 系统本地账号密码，不依赖外部身份认证。
- AI：公司内部模型服务。
- 使用方式：每人独立维护文档；同一远程仓库允许多人分别 Clone。
- 部署：Linux、Nginx HTTPS、systemd；优先保持 Node.js 单体应用。
- 数据隔离：用户独立工作区、独立本地 Git Clone；不共享可写工作目录。

## 实施边界

当前继续完善个人版，不在个人版主分支引入多用户认证、数据库或团队工作区。团队版分支应从个人版经过功能回归、真实文档交付验收并打 Tag 的稳定提交创建。

## 版本策略

个人版与团队版共享成熟的 DITA 业务核心，但独立发布。个人版的通用缺陷修复可经评估同步到团队版；团队版专属的认证、权限、用户状态和运维代码不反向合入个人版。
