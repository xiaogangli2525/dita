    项目型号清单
    每行一个型号。配置保存在当前 Git 仓库，清单仅用于校验，不会批量改动文档。留空表示尚未启用清单校验。

    恢复未保存草稿
    仅显示当前仓库和分支。恢复前会核对磁盘版本；草稿保存在当前浏览器。
    
    
    
    
    
      
  
    
    交付记录
    记录下载发起时的型号、版本、源文件指纹与未保存状态。保留当前浏览器中此仓库最近 50 条记录；可下载 JSON 随交付归档。
    
    
    
      
  
    
    
    加载远程文档库
    将仓库克隆到服务所在机器的工作区，再选择要编写的功能手册。
    
    
    
    私有库使用运行服务机器已有的 Git 凭据或 SSH 配置，请勿在地址中填写密码或 Token。
    
    
    
    
    
    
    
  
    
  
    
    远程更新
    检查更新会读取远程版本。拉取仅执行快进更新；本地改动和分叉需先在 Git 中处理。
