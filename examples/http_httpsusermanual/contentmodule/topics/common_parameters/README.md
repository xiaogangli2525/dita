# 简单DITA参数文件示例

## 概述
这是一个简单而实用的DITA参数文件示例，既便于conref引用，又考虑知识图谱构建的需求。

## 文件结构

### 1. `product_parameters.dita` - 产品参数库
- **目的**：存储所有产品模组的标准参数
- **结构**：按参数类型分组（封装、尺寸、重量、功率、温度、电压、频段、速率）
- **特点**：每个参数都有唯一的ID，便于conref引用

### 2. `product_configurations.dita` - 产品配置表
- **目的**：定义各产品型号的具体参数配置
- **结构**：按产品型号分组，使用conref引用参数库
- **特点**：便于知识图谱构建，明确产品-参数关系

### 3. `parameter_test.dita` - 参数引用测试
- **目的**：验证conref引用功能是否正常工作
- **内容**：包含各种参数引用示例
- **用途**：测试和验证参数文件的正确性

### 4. `new_product_template.dita` - 新产品文档模板
- **目的**：为新型号产品提供标准化的文档模板
- **内容**：包含完整的产品概述表格模板
- **特点**：使用conref引用参数库，便于快速创建新产品文档

### 5. `ml307c_example.dita` - ML307C产品文档示例
- **目的**：展示如何使用模板创建实际的产品文档
- **内容**：基于模板创建的ML307C产品概述
- **用途**：作为使用模板的参考示例

### 6. `parameter_test.ditamap` - DITA地图
- **目的**：包含所有参数文件，确保conref引用正常工作
- **内容**：引用所有参数文件、模板和测试文件

## 使用方法

### Conref引用示例
```xml
<!-- 引用封装类型 -->
<ph conref="product_parameters.dita#product_parameters/package_lcc48_lga61"/>

<!-- 引用尺寸规格 -->
<ph conref="product_parameters.dita#product_parameters/dimensions_17_7x15_8x2_2"/>

<!-- 引用重量规格 -->
<ph conref="product_parameters.dita#product_parameters/weight_1_2g"/>
```

### 测试验证
1. 在Oxygen XML Editor中打开 `parameter_test.ditamap`
2. 预览或转换此地图
3. 检查 `parameter_test.dita` 中的conref引用是否正确解析
4. 如果显示具体参数值而不是"[Conref was not expanded]"，说明引用成功

## 知识图谱支持

### 实体定义
- **产品实体**：ML307C, M5310-E等
- **参数实体**：封装类型、尺寸规格、重量规格等
- **属性关系**：产品-参数对应关系

### 关系映射
- **产品分类**：LTE Cat.1模组、NB-IoT模组
- **参数重用**：通过conref机制定义参数共享关系
- **层次结构**：产品型号 → 参数类型 → 参数值

## 优势

1. **简单直接**：避免复杂的转换过程
2. **便于维护**：只需要维护DITA文件
3. **引用可靠**：使用DITA标准的conref机制
4. **知识图谱友好**：结构化的表格和引用关系
5. **扩展性好**：便于添加新的产品型号和参数

## 新产品开发流程

### 使用模板创建新产品文档
1. **复制模板**：复制 `new_product_template.dita` 文件
2. **重命名文件**：将文件名改为新产品型号
3. **替换产品信息**：将模板中的"NEW_PRODUCT"替换为实际产品型号
4. **选择参数**：从参数库中选择适合的参数，删除不适用的参数行
5. **添加特有参数**：如果产品有特有参数，在相应位置添加
6. **验证引用**：确保所有conref引用都正确解析
7. **更新地图**：在产品的地图中包含新创建的文档

### 参数选择指南
- **LTE Cat.1模组**：使用LCC48+LGA61封装、17.7mm*15.8mm*2.2mm尺寸等参数
- **NB-IoT模组**：使用LCC+LGA封装、19mm±0.2mm*18.4mm±0.2mm*2.2mm±0.2mm尺寸等参数
- **LTE Cat.4模组**：使用LCC44+LGA50封装、17.7mm*15.8mm*2.4mm尺寸等参数
